# Final palette update — Signal / Ochre

The previous blue/green and burgundy/aubergine pairs were removed. The site now uses a warmer editorial poster palette that sits naturally on the existing paper/ink foundation.

## Core colours
- Paper: `#F2EFE6`
- Ink: `#12120F`
- Primary / Signal orange: `#E84A27`
- Secondary / Muted ochre: `#D2A233`
- Warm highlight: `#F2C14E`

## Supporting category colours
- Terracotta: `#C76A4B`
- Dusty violet: `#6C5A8C`
- Ochre: `#B9842F`
- Stone: `#7B7368`

## Why this direction
The brand no longer depends on a fashionable colour pair. The core identity is paper + ink + one strong signal colour. Ochre appears only as a secondary editorial marker, while the remaining hues are reserved for category coding. This keeps the site from feeling like a generic SaaS or AI-generated gradient theme.

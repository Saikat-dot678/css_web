# Events + Team update — v3

## Events
- Every event has a poster. If no real poster is uploaded, the prototype generates a unique 4:5 CSS event poster automatically.
- Admin can replace the generated poster with an image URL or local image upload.
- Events page is now poster-first with Featured, Upcoming, Ongoing, and Past sections.
- Past events remain visible as a poster archive and open full event-detail/recap pages.
- Event detail includes poster, date/time/venue/eligibility/entry, optional speakers, schedule, registration form, recap, gallery, resources/results, and related events.
- Added example past events so the archive can be evaluated immediately.

## Team
- Removed the ledger/table-style member directory.
- Final-year B.Tech students are represented only as **Office Bearers**; there is no duplicate Final Year section.
- Current and archived committees are divided into:
  - Office Bearers — Final Year
  - Third Year
  - Second Year
  - M.Tech
  - PhD
- Members are shown in rectangular cards with photo/initials, role, programme, working group, LinkedIn, Instagram, and Facebook.
- Faculty coordinators are shown before the student hierarchy.
- Previous committee years reuse the same card structure.
- Admin member creation now stores academic group, working group, photo URL, and all three social links.
